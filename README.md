# LotusWebAgency organization profile

This repository contains the public profile displayed on the
[LotusWebAgency GitHub organization](https://github.com/LotusWebAgency).

GitHub renders [`profile/README.md`](profile/README.md) on the organization's
Overview page. The banner in `profile/assets/` is shared with the main
LotusWebAgency brand so the organization and website stay visually consistent.
